DecoderArgument

Description

the parameters of the golden record image decoder.

the windowSize and the offset are the legacy parameters of the original implementation which cut a fixed sample window for locating the scan line start. the new decoding pipeline measures the scan line period and the pixel clock from the waveform data itself, so those two parameters are kept only for the backward compatibility of the existing R# scripts and they are no longer used.

Declare

            
# namespace voyager_1
export class DecoderArgument {
   # apply the per scan line synchronization for removing the residual jitter of the analog recording
   align: boolean;
   # the maximal per scan line alignment shift (in samples)
   align_window: integer;
   # the length (in samples) of the baseline tracking window, zero for the whole scan line mean value
   baseline_window: integer;
   # the number of the samples which are skipped after the sync pulse position
   guard: double;
   # the expected number of the scan lines of the image, zero for auto detect
   lines: integer;
   # the intensity estimator of a pixel cell, the default Mean mode is the signed mean of the cell samples (the legacy decoder estimator), the Absolute/Rms modes rectifies the samples and they are much noisier
   mode: DemodulationMode;
   # (legacy) the sync pulse offset of the original scan line locator
   offset: integer;
   # the scan line period (in samples), zero for auto detect and refine
   period: double;
   # the samples per pixel cell, zero means it is evaluated from the scan line period
   pixel_pitch: double;
   # the number of the pixel cells inside a single scan line
   pixels: integer;
   # remove the per scan line baseline drift before the amplitude rectification
   remove_baseline: boolean;
   # the legacy switch of the Rms intensity estimator, it overrides the mode property when it is enabled
   use_rms: boolean;
   # (legacy) the fixed sample window size of the original scan line locator
   windowSize: integer;
}
