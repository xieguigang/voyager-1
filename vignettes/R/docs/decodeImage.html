decodeImage {voyager1} R Documentation

Decode a grayscale image on the disk

Description

the scan line period and the pixel clock are measured from the waveform data itself (see the decode.report function), the legacy windowSize and offset parameters of the decoder are not used any more.

Usage

decodeImage(start, wavFile,
    size = 364,
    lines = 512,
    white = 1,
    gamma = 1,
    percentile = NULL,
    palette = 'gray',
    smooth = 0,
    luminous = FALSE,
    report = FALSE);

Arguments

start

the data start position on the raw wav file

wavFile

the file path of the wav file

size

the pixel cells (the image rows) inside a single scan line, default 364

lines

the number of the scan lines (the image columns), default 512

white

the white point gain of the rendering, 1 means no adjustment

gamma

the gamma correction of the rendering, 1 means no correction

percentile

the black point and the white point percentiles of the auto levels

palette

the palette name of the pseudo color rendering

smooth

the radius of the across scan line smoothing, 0 for disable. the smoothing is disabled by default because it reduces the edge contrast of the decoded image and makes it look blurred

luminous

render the image as the pseudo color image

report

print the empirical analysis report of the data section
