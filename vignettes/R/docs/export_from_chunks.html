export_from_chunks {voyager1} R Documentation

A pre-defined list of the image locations

Description

the frame length of an image data section, the calibration circle image section is about 1928181 sample frames long the pixel cells (the image rows) inside a single scan line the number of the scan lines (the image columns) of a single image make batch export of the images on the disk

Usage

export_from_chunks(wavFile, output.dir,
    size = image_pixel_size,
    lines = image_scan_lines,
    smooth = 0,
    report = FALSE);

Arguments

wavFile

the file path to the disk image in wave file

output.dir

the directory path for export the image files

size

the pixel cells (the image rows) inside a single scan line

lines

the number of the scan lines (the image columns)

smooth

the radius of the across scan line smoothing

report

print the empirical analysis report of every image section
