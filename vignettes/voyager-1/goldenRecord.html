.NET clr type export
image.chunk: ImageChunk
decode: DecoderArgument

the parameters of the golden record image decoder.

the windowSize and the offset are the legacy parameters of the original implementation which cut a fixed sample window for locating the scan line start. the new decoding pipeline measures the scan line period and the pixel clock from the waveform data itself, so those two parameters are kept only for the backward compatibility of the existing R# scripts and they are no longer used.
decode.report: DecodeReport

the empirical analysis report of a given image data section on the golden record wave file.

all of the decoder parameters (scan line period, pixel clock, brightness encoding, color component) are measured from the real waveform data instead of guessing.


.NET clr function exports
decode

Decode the wav data as the image pixels.

the scan line period and the pixel clock are measured from the waveform data itself (see the decode.report function for the empirical analysis), the offsetLeft/offsetRight parameters of the original implementation are kept only for the backward compatibility of the existing scripts.
decode.report

the empirical analysis of an image data section: the scan line period, the pixel clock, the brightness encoding scheme, the left/right channel relationship and the color component detection result.
write_csv

write the image decode intensity data as csv file
as.bitmap

render the decoded pixels as a gray scale or a pseudo color bitmap image.

the intensity data is normalized by the percentile based auto levels, and the polarity is inverted by default because the image data of the golden record is stored as a photographic negative.
chunk_size

measure the data chunk size of the wav data for current image chunk
