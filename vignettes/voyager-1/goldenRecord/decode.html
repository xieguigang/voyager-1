decode {goldenRecord} R Documentation

Decode the wav data as the image pixels.

Description

<br /> the scan line period and the pixel clock are measured from the waveform data<br /> itself (see the decode.report function for the empirical analysis), the<br /> offsetLeft/offsetRight parameters of the original implementation are<br /> kept only for the backward compatibility of the existing scripts.

Usage

decode(wav, chunk, decode,
    size = 0,
    offsetLeft = 0.2,
    offsetRight = 0.2,
    pixels = 0,
    lines = 0,
    align = TRUE,
    guard = 0,
    mode = "mean");

Arguments

wav

[as WaveFile]

chunk

[as ImageChunk]

decode

the decoder arguments, the invalid values are filled by the measured ones. [as DecoderArgument]

size

the pixel cells (the image rows) per scan line, 0 for the default 364. [as integer]

pixels

the alias of the size parameter, the value of size wins when both are assigned. [as integer]

lines

the number of the scan lines (the image columns), 0 for the default 512. [as integer]

align

apply the per scan line synchronization. [as boolean]

guard

the samples which are skipped after the sync pulse position. [as double]

mode

the pixel cell intensity estimator: mean (the default, the signed mean of the cell samples, it matches the legacy decoder result), abs (the rectified mean) or rms. the rectified estimators are much noisier. [as string]

env

[as Environment]
