as.bitmap {goldenRecord} R Documentation

render the decoded pixels as a gray scale or a pseudo color bitmap image.

Description

<br /> the intensity data is normalized by the percentile based auto levels, and the<br /> polarity is inverted by default because the image data of the golden record is<br /> stored as a photographic negative.

Usage

as.bitmap(pixels,
    luminous = FALSE,
    white = 1,
    gamma = 1,
    invert = TRUE,
    percentile = NULL,
    palette = "gray",
    smooth = 0,
    height = 0);

Arguments

pixels

[as PixelDecode]

luminous

render as a pseudo color image. [as boolean]

white

the white point gain, 0 or 1 means no adjustment. [as double]

gamma

the gamma correction, 1 means no correction. [as double]

invert

the black/white polarity. [as boolean]

percentile

the black point and the white point percentiles, like c(0.005, 0.995). [as double]

palette

the palette name of the pseudo color rendering. [as string]

smooth

the radius of the across scan line smoothing, 0 for disable. [as integer]

height

the output image height in pixels, 0 for keep the original size. [as integer]
